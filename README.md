# Стикер-планер

Календарь-планировщик на месяц: дни-кружки, стикеры проектов по бокам,
метки «универ» и «спорт» над днями и нить с физикой между двумя днями.

## Как пользоваться

- **Покрасить день.** Клик по стикеру включает красящий режим, курсор
  становится цветным кружком. Клик по дню добавляет на него активность,
  повторный клик тем же цветом её убирает. Несколько активностей делят
  круг на равные доли: половины, трети и так далее, до шести. Клик по фону
  или Escape выключает режим.
- **Ластик** под календарём стирает цвет с дня. Правый клик по дню делает
  то же самое.
- **Метки.** Наведите курсор на верхнюю часть дня — появится серый кружок.
  Клик ставит «универ», следующий переводит в «спорт», следующий убирает.
  Больше одной метки каждого вида в день не поставить.
- **Нить.** Потяните за фиолетовый кружок и отпустите на любом дне раньше
  исходного. Верёвка считается по Верле: гравитация, затухание, 16 итераций
  на кадр. Клик по серому концу отвязывает её.
- **Проекты.** Кружок в левом верхнем углу стикера меняет цвет, клик по
  названию переименовывает, крестик убирает проект. Серый стикер в конце
  каждой колонки заводит новый. Число проектов не ограничено: стикеры
  уменьшаются, чтобы поместиться в колонку.
- Стрелки влево и вправо листают месяцы.

## Где что лежит

- `planner.html` — исходник. Это тело страницы без `doctype`, `html`,
  `head` и `body`: именно в таком виде его принимает Claude Artifacts,
  который дописывает обвязку сам.
- `index.html` — то же самое, обёрнутое в самостоятельный документ.
  Открывается двойным кликом и годится для GitHub Pages. Собирается из
  исходника: `./build.sh`.

Правьте `planner.html`, потом запускайте `./build.sh`.

## Сохранение

Новая доска открывается пустой. Состояние пишется в `localStorage` браузера и, когда страница опубликована
как артефакт с capability `db`, дублируется в общее хранилище артефакта
(документ `planner/board3`) — тогда доска синхронизируется между
устройствами и вкладками. Без хранилища остаётся локальная копия.

Зависимостей нет, сборки нет, шрифты Caveat и Nunito подтягиваются с
Google Fonts.
